## Введение

**HACS Vision** — современная визуальная панель для HACS со встроенным магазином. Она позволяет просматривать, устанавливать, обновлять и администрировать интеграции, плагины и темы Home Assistant так же удобно, как приложения в обычном магазине. Config Flow и Options Flow любых интеграций Home Assistant можно открывать прямо из панели. Интерфейс HACS Vision полностью переведён на русский язык.

## Возможности

- **🛒 Магазин** — поиск, фильтры по категориям, сортировка, избранное и переключение между карточками и списком.
- **⭐ Звёзды репозиториев** — локальное избранное и GitHub Stars управляются независимо; звёздочку можно поставить или убрать одним нажатием.
- **🔑 Авторизация GitHub** — вход по токену или OAuth, отдельное безопасное хранение и автоматическое восстановление сеанса.
- **📦 Пакетное добавление репозиториев** — укажите организацию или пользователя GitHub, выберите несколько репозиториев и добавьте их одним действием.
- **🔄 Управление обновлениями** — просмотр доступных обновлений, отслеживание прогресса, одиночные и пакетные операции, а также игнорирование ненужных репозиториев.
- **📦 Управление репозиториями** — установленные версии, история, повторная загрузка, удаление, фильтрация и сортировка.
- **⚙️ Настройка интеграций** — запуск Options Flow установленных интеграций Home Assistant непосредственно из панели.
- **🔌 Добавление интеграций** — запуск Config Flow интеграций Home Assistant из HACS Vision.
- **📊 Статистика** — актуальное количество установленных репозиториев, обновлений и элементов избранного.
- **🔔 Уведомления** — уведомления о доступных обновлениях с оптимизированным кешированием.
- **📱 Адаптивный интерфейс** — оптимизация для настольных компьютеров и мобильных устройств, сенсорные элементы высотой не менее 44 пикселей.
- **🧩 Управление интеграциями** — карточки всех установленных интеграций, поиск, фильтрация по состоянию и группировка по категориям.
- **🔍 Просмотр устройств и сущностей** — переход от интеграции к устройствам, областям и состояниям сущностей в реальном времени.
- **🎮 Управление сущностями** — переключатели, свет, замки, шторы и вентиляторы управляются прямо из панели.
- **🌐 Русская локализация** — русский интерфейс выбирается вручную или автоматически по языку Home Assistant; предусмотрен английский fallback.
- **🎨 Значки брендов** — трёхуровневая загрузка: CDN, локальный значок и резервный вариант с первой буквой.
- **🔗 EntityRefFinder** — поиск всех ссылок на `entity_id` в автоматизациях, скриптах, сценах и панелях с возможностью замены.
- **🔄 Повторная загрузка** — переустановка повреждённого репозитория одним действием.
- **⛔ Игнорирование репозиториев** — скрытие выбранных репозиториев из поиска и уведомлений об обновлениях.
- **🖼️ Встроенная страница настройки** — собственная страница интеграции Home Assistant открывается в модальном iframe с полноэкранным режимом.
- **🧩 Формы Config Flow** — удобное отображение полей и вариантов выбора с переходом между шагами.
- **🤖 Автоматические обновления** — фоновое обновление репозиториев из белого списка с настраиваемыми интервалами, уведомлениями и индивидуальными переключателями.

## Установка

### Через пользовательский репозиторий HACS (рекомендуется)

> ⚠️ **HACS Vision отсутствует в стандартном магазине HACS**, поэтому его нельзя найти обычным поиском. Сначала добавьте этот репозиторий в список пользовательских.

1. Убедитесь, что [HACS](https://hacs.xyz) установлен.
2. Перейдите в **HACS → Интеграции → Пользовательские репозитории** (меню в правом верхнем углу).
3. Добавьте URL-адрес репозитория: `https://github.com/C3H3-AI/hacs-vision`.
4. Категория: **Интеграция**
5. Нажмите **Установить**.
6. **Перезагрузите Home Assistant**

### Ручная установка

1. Загрузите [последний выпуск](https://github.com/C3H3-AI/hacs-vision/releases).
2. Скопируйте `custom_components/hacs_vision` в каталог `custom_components/` Home Assistant.
3. Перезапустите Home Assistant.

---

## Настройка

1. Откройте **Настройки → Устройства и службы → Добавить интеграцию**.
2. Найдите **HACS Vision**.
3. Нажмите **Отправить** — дополнительная настройка не требуется.
4. HACS Vision появится в боковом меню.

## Использование

### 🛒 Магазин

Просматривайте доступные репозитории HACS, используйте поиск и объединённые фильтры по состоянию, тегам и типу. Репозитории можно добавлять в избранное, повторно загружать или игнорировать. Доступны представления в виде карточек и списка.

### 🔄 Обновления

Здесь отображаются репозитории с доступными обновлениями. Нажмите **Обновить все** либо отметьте нужные репозитории и выберите **Обновить выбранное**. Поддерживается пакетное удаление.

### 📦 Управление

Управляйте установленными репозиториями с помощью фильтров по **состоянию**, **типу** и группе репозитория (все, архивные, переименованные или игнорируемые). Доступны сортировка и пакетные операции.

### 🧩 Управление интеграциями

Все установленные интеграции Home Assistant представлены в виде карточек с поиском, фильтром состояния и пакетными операциями. **Нажмите карточку**, чтобы открыть встроенную страницу настройки Home Assistant; двойной щелчок включает полноэкранный режим. Кнопка **⚙ Настроить** открывает Options Flow выбранной интеграции.

## Список изменений

### v6.5.1 (16 июля 2026 г.) — Локальное сохранение результатов перевода
- **Оптимизировано**: **Результаты перевода кешируются локально** — переведённый README хранится в `localStorage` браузера (по умолчанию 7 дней, до 1 МБ на запись, LRU-вытеснение после 50 записей). После закрытия окна, обновления страницы или перезапуска Home Assistant кешированный перевод отображается **мгновенно, без обращения к LLM** — без задержки и расхода токенов.
- **Бонус**: репозитории, переведенные ранее, по-прежнему можно просматривать даже без настройки ИИ перевода в настройках (для попадания в кэш не требуется запрос backend, что также позволяет избежать проблемы с токеном 404 стороннего репозитория GitHub).

### v6.5 (16 июля 2026 г.) — README AI-перевод (стабильный) и оптимизация пользовательского интерфейса
- **Новое**: **README AI Translation** — переключатель языка (оригинальный/китайский/английский/немецкий, дополнительно японский/корейский) в диалоговом окне репозитория; использует настроенный вами ассистент разговора HA («Настройки → Голосовые помощники») (например, MiMo / GPT / Ollama), дополнительный ключ API не требуется
- **Новое**: **Настраиваемая система перевода** — новый раскрывающийся список «README Translation AI» в основных настройках, автоматически выводит список всех объектов `conversation.*`.
- **Новинка**: **Кэш переводов** — результаты кэшируются на стороне сервера на 6 часов.
- **Оптимизация**: **Скрыть кнопки перевода, если искусственный интеллект не настроен** — если искусственный интеллект перевода не установлен, языковая панель заменяется подсказкой.
- **Стабильность**: **На основе стабильной версии 6.4.4 Core** — удален неработающий параметр тайм-аута, возврат к стабильному пути трансляции.

## Разработка

### Сборка frontend

```bash
cd frontend_src
npm install
npm run build
```

Результат сборки записывается в `custom_components/hacs_vision/frontend/`.

### Механизм перевода

Диалог настройки получает локализацию через backend API `/api/hacs_vision/translations/{domain}?lang=ru`. API читает файлы из каталога `custom_components/{domain}/translations/` выбранной интеграции. Метод frontend `_t()` поддерживает структуры ключей Config Flow и Options Flow Home Assistant.

## Часто задаваемые вопросы

**В: Чем HACS Vision отличается от HACS?**  
О: HACS Vision — дополнительная визуальная панель, которая использует HACS как backend и не заменяет его.

**В: Можно ли устанавливать репозитории из HACS Vision?**  
О: Да. Откройте магазин, выберите репозиторий и нажмите **Установить**.

**В: Почему отдельные поля настройки остаются на английском?**  
О: Перевод Config Flow зависит от файлов локализации самой настраиваемой интеграции. Если её автор не предоставил `ru.json` или оставил в нём английский текст, HACS Vision использует доступный fallback.

**В: Почему панель сообщает, что HACS недоступен?**  
О: Убедитесь, что HACS правильно установлен и настроен.

**В: Как обновить HACS Vision?**  
О: При установке через HACS обновление появится на странице обновлений. При ручной установке замените файлы интеграции файлами из последнего выпуска.
